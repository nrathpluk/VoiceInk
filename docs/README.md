## วิธีอัด demo.gif

1. ติดตั้ง [ScreenToGif](https://www.screentogif.com/) (free, Windows)
2. เปิด `python main.py`
3. ScreenToGif → Recorder → ครอบเฉพาะแคปซูล + พื้นที่ clipboard target
4. แสดง flow: idle → กด hotkey → recording (สีแดง) → กดอีกครั้ง → processing → "Copied!" → paste ลง notepad
5. Editor → Reduce frame rate ~12 fps, ตัดให้ ≤8 วินาที
6. Save as `docs/demo.gif` (target ≤2 MB)

## ขนาดแนะนำ

- กว้าง 600–800 px
- ≤8 วินาที
- ≤2 MB (GitHub README โหลดเร็ว)
